twitch2yt

Политика конфиденциальности · личное приложение

twitch2yt — личное приложение для записи трансляций на Twitch и загрузки записей на собственный канал YouTube. Приложение используется одним человеком — владельцем канала, — и не предоставляется другим пользователям.

Какие данные использует приложение

Приложение запрашивает единственную область доступа Google: https://www.googleapis.com/auth/youtube.upload — загрузка видео на канал YouTube.

  • Приложение не читает список видео, статистику и комментарии.
  • Приложение не имеет доступа к контактам, почте, диску и другим сервисам аккаунта.
  • Приложение не запрашивает и не хранит пароль от Google-аккаунта.

Хранение данных

Данные авторизации (файл token.json) хранятся только на компьютере владельца канала. Видеофайлы обрабатываются локально и загружаются напрямую в YouTube через официальный API.

Передача данных третьим лицам

Приложение не собирает, не продаёт и не передаёт персональные данные третьим лицам. Данные не используются для рекламы и аналитики.

Отзыв доступа

Доступ приложения можно в любой момент отозвать на странице myaccount.google.com/permissions. После отзыва приложение теряет возможность загружать видео.
